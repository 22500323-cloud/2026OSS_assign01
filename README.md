## Code Modification

AI를 활용하여 만든 index.html을 복사하여 index2.html을 만들었습니다.

이후 index2.html에서 다음과 같은 내용을 직접 수정했습니다.

1. 자기소개 텍스트와 내용을 변경했습니다.
2. GitHub Repository로 이동할 수 있는 외부 링크를 추가했습니다.
3. 페이지의 일부 내용과 구성을 수정했습니다.

이를 통해 AI가 생성한 원본 코드와 직접 수정한 코드의 차이를 확인할 수 있었습니다.

---

## Problem & Solution

실습 중 처음에는 Git 명령어를 실행하는 폴더가 Git Repository가 아니어서 
"fatal: not a git repository" 오류가 발생했습니다.

문제를 확인한 후 실제 프로젝트 폴더로 이동하여 Git 상태를 확인하고, 
올바른 Git Repository에서 add, commit, push 작업을 진행하여 문제를 해결했습니다.

또한 Vercel에서 이전 페이지가 표시되는 문제가 있었지만, 
GitHub Repository 연결 상태를 확인하고 최신 변경 사항을 Push한 후 
정상적으로 배포되는 것을 확인했습니다.

---

## Reflection

이번 실습을 통해 단순히 HTML 파일을 만드는 것뿐만 아니라, 
Git을 이용해 작업 내용을 버전별로 관리하고 GitHub와 연결하는 과정을 배웠습니다.

특히 GitHub에 Push한 변경 사항이 Vercel과 연결되어 자동으로 웹사이트에 
반영되는 과정이 인상적이었습니다. 앞으로는 Git과 GitHub의 다양한 기능과 
웹사이트 배포 과정을 더 깊게 공부해보고 싶습니다.
